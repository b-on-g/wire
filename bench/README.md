# $bog_wire_bench

Один и тот же поток заказов на пяти стеках. N заказов добавить, все перезаписать, все отменить, после каждой фазы посчитать сумму. На каждый заказ создаётся строка, которая читает свой заказ и должна умереть после отмены.

- `bench.wire`, `bench.native.wire` — wire: граф без сборщика, команды читаются из stdin;
- `rust-wire` — тот же граф на `wire.rs` из ветки `rust` mam_mol (`1065716194`), арена с поколениями;
- `node` — тот же граф на `$mol_wire` (`mol_wire_lib` 1.0.1845) поверх сборщика V8;
- `go` — push: подписка на заказ, сумма правится на разницу, ручная отписка при отмене;
- `rust` — чистый Rust без реактивности: вектор, словарь и цикл.

Модель во всех графах одна, как в `salt`: список `ids` и канал `order( id )` на каждый заказ, строка `line( id )`, сумма по строкам. Id заказов числовые.

```sh
bog/wire/bench/run.sh
bog/wire/bench/run.sh 300 1000
```

Нужны `node`, `zig`, `cargo`, `go`. Скрипт собирает всё в `-/`, генерирует ввод и печатает медиану пяти прогонов: выполненные инструкции и пик занятой оперативки по `/usr/bin/time -l`. Счётчик инструкций есть только на macOS.

## Результаты

macOS, arm64, 10 000 заказов:

- wire: 5,5 млрд инструкций, 24,2 МБ;
- rust-wire: 3,2 млрд, 19,0 МБ;
- node: 523 млрд, 385 МБ;
- go: 0,12 млрд, 9,9 МБ;
- rust: 0,45 млрд, 2,8 МБ.

После всех отмен живых строк ноль везде: wire проверяет это при выходе из `main`, rust-wire печатает `alive()`, node считает строки в деструкторе, go считает подписки.
